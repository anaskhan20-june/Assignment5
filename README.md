# Assignment 5: Python Data Structures

This repository contains Python scripts demonstrating fundamental data structure concepts, including list creation, accessing elements, list slicing, and reversing lists.

## Tasks Overview

### Task 1: Working with Lists (`task_1.py`)

- Creates and initializes a Python list with multiple elements.
- Demonstrates accessing elements from the list using indexing.
- Performs basic operations on the list to understand how Python lists work.
- Displays the results using formatted output.

### Task 2: List Slicing and Reversing (`task_2.py`)

- Creates a list containing numbers from 1 to 10.
- Uses list slicing to extract the first five elements.
- Demonstrates the use of the slicing syntax `[start:stop:step]`.
- Reverses the extracted elements using a negative step (`[::-1]`).
- Displays the original list, extracted elements, and reversed elements.
